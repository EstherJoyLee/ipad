# **iPad Landing Page Clone 📱✨**

🚀 Apple 공식 iPad 소개 페이지를 클론한 정적 웹 프로젝트입니다.  
iPad 제품의 기능, 장점, 액세서리, 비교 페이지 등 상세한 구조를 **HTML, CSS, JavaScript만으로 정교하게 구현**했습니다.

📌 이 프로젝트는 비상업적 클론 코딩으로, **Apple의 UI 구조와 인터랙션을 학습**하고 재현하는 데 중점을 두었습니다.

---

## **📌 주요 기능**

- Apple iPad 공식 페이지 구조 완벽 재현
- Hero Section / Power / Display / Camera / iPadOS / Privacy 등 섹션 구성
- 스크롤 기반 콘텐츠 등장 애니메이션 구현
- iPad 모델별 카드 구성 및 동적 렌더링 (`ipads.js`)
- Footer 내 내비게이션 메뉴를 데이터 기반으로 생성 (`navigations.js`)
- 반응형 레이아웃 설계 (PC / 태블릿 대응)
- 비디오 재생 / 정지 버튼 전환 구현
- 검색 영역, 장바구니, 모바일 메뉴 toggle 인터랙션 구현

---

## **🛠 기술 스택**

- HTML5  
- CSS3  
- JavaScript (Vanilla JS + ES6 Modules)  

---

## **💡 주요 코드 특징**

- `IntersectionObserver`로 섹션별 등장 애니메이션 구현
- `ipads.js`로부터 데이터를 가져와 iPad 모델 카드 UI를 동적 생성
- `navigations.js` 데이터를 기반으로 Footer 메뉴 자동 구성
- Header 및 Navigation의 **토글형 메뉴**, **검색창**, **장바구니** 등은 모두 JavaScript로 구현
- Video 태그와 함께 컨트롤 버튼을 통해 **수동 재생/정지 기능 지원**
